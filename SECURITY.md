# Security policy

AI Three.js Studio is in private beta. Security reports are welcome and should
not be filed as public GitHub issues when they include exploit details, secrets,
or user data.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting feature on this repository. Include
the affected component, reproduction steps, impact, and any suggested mitigation.
Please allow a reasonable period for investigation before public disclosure.

Do not test against accounts, projects, or infrastructure you do not own, and do
not perform denial-of-service or destructive testing against the hosted beta.

## Supported versions

Only the current `main` branch and the current hosted beta are supported while
the project is pre-release.
