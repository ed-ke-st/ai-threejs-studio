# Building Houses and Structures

Buildings are blocked out from simple boxes: a main mass for the walls, a roof, and inset details (door, windows, chimney). Build each building as one named group so it can be placed and scaled as a unit, and rest it on the ground.

## Massing and parts

Start with the walls as a single box sized to the footprint and storey height. Add a roof on top — a flattened pyramid (a cone with 4 radial segments, rotated 45 degrees to align with a square footprint) for a pitched roof, or a thin box for a flat roof. Then add details as thin boxes sitting just proud of the wall face: a door at floor level, windows higher up, a chimney box on the roof. For larger or taller buildings, repeat window boxes in a grid across each floor.

## Proportions

Treat 1 unit as roughly 1 metre. A single storey is about 2.5-3m tall; a cottage footprint is about 3-5m. A door is about 0.9 x 2m, windows about 0.8 x 1m. Keep the roof height proportional to the walls (roughly half to three-quarters of the wall height).

## Materials and lighting

Walls: plaster, brick, or wood — medium-high roughness, no metalness. Roof: a darker tile or thatch colour, often flatShading for a stylized look. Windows: light blue, low roughness, with a faint emissive so they read as lit at dusk. Light exteriors with hemisphere + a directional sun; light interiors through a window direction.

## Composition

Place the building on a ground plane and add context — a path, trees, a fence, or a few rocks — so it does not float in a void. Frame the camera at a three-quarter angle so two faces of the building are visible.

## Common failure modes

A single featureless box — always inset a door, windows, and a roof. A floating building — rest the walls on the ground. A roof that does not match the footprint — rotate a 4-sided cone 45 degrees, or size a box roof to overhang the walls slightly.
